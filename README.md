# Crazy Arcade

크아의 손맛을 되살린 **2D 아케이드 게임**입니다.

## 제작 배경

- 2026년 08월 13일은 크아 서비스 종료일입니다.
- 크아 15년차 유저로서, 크아의 손맛을 되살리고 싶었습니다.
- 직접 만들어서 개발 경험과 재미를 얻고자 시작한 프로젝트입니다.

## 게임 방법

[웹사이트](https://petit-ca.vercel.app/)에서 플레이하실 수 있습니다.

### 목표

상대방을 물풍선으로 가둬 아웃시켜야 합니다.

### 조작 방법

- 키보드 방향키로 캐릭터를 움직입니다.
- 스페이스 바로 물풍선을 놓습니다.
- 로컬 멀티 모드 선택 시 키보드 조작키는 다음과 같습니다.
  - 1P 캐릭터: R·D·F·G키로 이동하고, 좌측 시프트 키로 물풍선을 놓습니다.
  - 2P 캐릭터: 방향키로 이동하고, 우측 시프트 키로 물풍선을 놓습니다.

### 종료 조건

상대방이 모두 아웃되면 종료됩니다.
