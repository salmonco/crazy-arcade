# Crazy Arcade

크아의 손맛을 되살린 **2D 아케이드 게임**입니다.

## 제작 배경

크아 서비스 종료(2026.08.13)가 계기가 되었습니다.
크아 15년차 유저로서, 크아의 손맛과 스릴을 다시 느끼고 싶었습니다.
직접 만들면 개발 경험도 쌓일 것 같았습니다.
결론적으로 오직 저의 재미를 위해 만들기로 했습니다.

## 게임 방법

### 목표

상대방을 물풍선으로 가둬 아웃시켜야 합니다.

### 조작 방법

- 키보드 방향키로 캐릭터를 움직입니다.
- 스페이스 바로 물풍선을 놓습니다.
- 로컬 멀티 모드 선택 시 키보드 조작키는 다음과 같습니다.
  - 1P 캐릭터: R·D·F·G키로 이동하고, 좌측 시프트 키로 물풍선을 놓습니다다.
  - 2P 캐릭터: 방향키로 이동하고, 우측 시프트 키로 물풍선을 놓습니다.

### 종료 조건

상대방이 모두 아웃되면 종료됩니다.
